# Self-Promotional React SPA

This project is a self-promotional Single Page Application created with React.

The application introduces me, shows basic information about me, my skills, and safe contact information.

## Features

- Personal introduction
- Profile image
- About Me section
- Skills section
- Contact section
- Responsive design
- React components
- Single Page Application structure

## React Components

The project includes several React components:

- Navbar
- Hero
- About
- Skills
- Contact
- Footer

## Technologies

- React
- JavaScript
- HTML
- CSS
- Vite
